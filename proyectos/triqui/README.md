# Triqui en Python

Primer proyecto del Mes 1 del portafolio. Es un juego de triqui para dos jugadores en la terminal.

## Qué practiqué

- Variables y listas bidimensionales.
- Ciclos `for` y `while`.
- Condicionales.
- Entrada de datos con `input()`.
- Validación de casillas ocupadas.
- Comprobación de filas, columnas y diagonales.

## Cómo ejecutarlo

Desde esta carpeta ejecuta:

```bash
python triquitriqui.py
```

Cada jugador debe ingresar la fila y la columna separadas por un espacio. Los valores válidos van de `0` a `2`.
