# Python Data Portfolio

Mi portafolio de aprendizaje y proyectos de Python y análisis de datos.

## Mi meta

Durante los próximos **3 meses** construiré una base sólida en Python para transformar datos en análisis claros, útiles y reproducibles. Al finalizar, quiero contar con un portafolio público que demuestre mi capacidad para obtener, limpiar, explorar, visualizar y comunicar información a partir de datos reales.

## Habilidades que aprenderé en 3 meses

- **Python:** sintaxis, funciones, módulos, manejo de errores y programación orientada a objetos.
- **Herramientas de trabajo:** Git, GitHub, entornos virtuales y notebooks de Jupyter.
- **Manipulación de datos:** NumPy, pandas, limpieza, transformación y combinación de conjuntos de datos.
- **Análisis exploratorio:** estadística descriptiva, identificación de patrones y formulación de preguntas.
- **Visualización:** Matplotlib, Seaborn y diseño de gráficos fáciles de interpretar.
- **Bases de datos:** SQL, consultas, filtros, agrupaciones y conexión con Python.
- **Obtención de datos:** archivos CSV/Excel, APIs públicas y web scraping responsable.
- **Comunicación:** documentación, storytelling con datos y conclusiones basadas en evidencia.

## Proyectos

1. **[Triqui en Python](proyectos/triqui/README.md)** — Juego para dos jugadores en la terminal. Primer proyecto del Mes 1.
2. **Análisis exploratorio de ventas** — Limpiar datos de ventas, identificar productos y períodos destacados, y presentar recomendaciones.
3. **Dashboard de indicadores públicos** — Obtener datos de una API y construir visualizaciones para seguir indicadores relevantes.
4. **Análisis de precios y tendencias** — Estudiar la evolución de precios a lo largo del tiempo usando pandas y series temporales básicas.
5. **Proyecto SQL de negocio** — Diseñar consultas sobre una base de datos para responder preguntas concretas y documentar los resultados.
6. **Proyecto final: historia con datos** — Combinar varias fuentes, realizar un análisis completo y comunicar una conclusión mediante un informe claro.
